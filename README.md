# 米游社多用户签到

AstrBot 米游社游戏每日签到插件。每个聊天用户的数据彼此独立，Cookie 不会写入插件全局配置，也不会被其他用户覆盖。

## 安装

将本目录放到 `AstrBot/data/plugins/`，在 AstrBot WebUI 重载插件。绑定数据会保存到 AstrBot 的插件数据目录，更新插件不会丢失。

## 指令

| 指令 | 说明 |
| --- | --- |
| `/mys扫码` | 使用米游社 App 扫码并自动绑定账号 |
| `/mys绑定 <Cookie>` | 绑定或更新当前用户的米游社账号 |
| `/mys签到 [游戏]` | 签到当前账号；不填游戏时签到 WebUI 已启用的全部游戏 |
| `/mys测试` | 验证当前账号 Cookie 与绑定角色 |
| `/mys推送到这里` | 将当前会话设为自动签到结果的推送位置 |
| `/mys我的` | 查看当前用户绑定的账号 |
| `/mys切换 <序号>` | 切换当前用户的默认账号 |
| `/mys解绑 [全部]` | 解绑当前账号，或解绑当前用户的所有账号 |
| `/mys全部签到` | 管理员立即为所有已绑定用户签到 |

游戏参数支持：`原神`、`崩铁`、`绝区零`、`崩坏3`、`未定`、`崩坏2`。

默认签到还会执行米游社社区“大别野”签到。可在 WebUI 中关闭 `enable_community_sign`，或通过 `community_forums` 配置其他板块（`5` 为大别野）。社区签到需要账号 Cookie 含 `stuid` 和 `stoken`；扫码绑定会自动提供这两个字段。

## 扫码绑定

在私聊中发送 `/mys扫码`，用米游社 App 扫描机器人发出的二维码，并在 App 内确认登录。插件会自动获取、验证并保存 Cookie，成功后将该账号设为当前账号和签到结果推送目标。二维码默认 120 秒有效，可通过 WebUI 的 `qr_timeout` 配置调整。

同一用户同时只能有一个待确认的二维码。扫码登录期间不需要继续发送消息；确认、取消、超时或失败都会在发起扫码的会话中通知。

升级到包含扫码修复的版本后，建议每个用户重新执行一次 `/mys扫码`，以刷新历史绑定中可能不完整的 Cookie。

## Cookie

在浏览器登录米游社国服页面后，从开发者工具复制完整 Cookie，再使用 `/mys绑定 <Cookie>`。Cookie 属于账号凭据，请仅在私聊中发送，且不要把机器人日志或 `users.json` 暴露给他人。

Cookie 过期后重新绑定即可。米游社可能要求在官方页面完成首次游戏签到或人机验证，这类风控不能由插件绕过。

自动签到结果推送的配置与排查见 [自动签到结果推送教程](docs/自动签到结果推送教程.md)。
