# astrbot_plugin_miyoushe_sign

AstrBot 插件：**米游社每日签到**

每天自动在米游社进行每日签到，支持：

- **米游社社区签到**（大别野等板块，可获得米游币/经验）
- **游戏签到**：原神、崩坏：星穹铁道、绝区零、崩坏3、未定事件簿、崩坏学园2

## 安装

1. 将 `astrbot_plugin_miyoushe_sign` 文件夹放入 AstrBot 的 `data/plugins/` 目录。
2. 在 AstrBot WebUI 中启用插件。
3. 在「插件管理 → 米游社每日签到」中填写你的米游社 Cookie。

## 配置说明

| 配置项 | 说明 |
| --- | --- |
| `cookie` | **必填**。米游社完整 Cookie。含 `stuid/stoken` 才能签到社区板块；浏览器 Cookie 可签到游戏 |
| `enable_community_sign` | 是否启用米游社社区每日签到（默认开启） |
| `community_forums` | 社区签到板块 gids，如 `["5"]`（5=大别野，2=原神，6=星穹铁道，1=崩坏3，8=绝区零，4=未定事件簿，3=崩坏学园2） |
| `enable_game_sign` | 是否启用游戏签到（默认关闭） |
| `games` | 启用的游戏 key：`genshin` / `starrail` / `zzz` / `honkai3rd` / `tears` / `honkai2` |
| `auto_sign_enable` | 每天是否自动签到（默认开启） |
| `auto_sign_time` | 每天自动签到时间（24 小时制，服务器时区），默认 `09:00` |
| `push_result` | 自动签到完成后是否把结果推送到已绑定的会话（默认关闭） |

## 聊天指令

| 指令 | 说明 |
| --- | --- |
| `/mys扫码` 或 `/米游社扫码登录` | 用米游社 App 扫码登录，自动获取并保存完整 Cookie（推荐） |
| `/mys签到` 或 `/米游社签到` | 手动执行每日签到 |
| `/mys测试` 或 `/米游社测试` | 测试 Cookie 是否有效 |
| `/mys绑定` 或 `/米游社绑定` | 绑定当前会话，用于接收自动签到结果推送 |
| `/mys帮助` 或 `/米游社帮助` | 查看帮助 |

## 扫码登录（推荐）

无需手动复制 Cookie：

1. 在聊天中发送 `/mys扫码`
2. 机器人会发来一张登录二维码（米游社 App 扫码登录）
3. 用**米游社 App** 扫描二维码，在手机上点击「确认登录」
4. 插件会自动获取完整登录凭证（stuid/stoken/mid/ltoken/cookie_token）并保存到配置
5. 发送 `/mys测试` 验证，`/mys签到` 立即签到

> 扫码后获取的 Cookie 同时兼容社区签到和游戏签到，比手动复制更可靠。若 120 秒内未完成扫码会超时，重新发送 `/mys扫码` 即可。

## 如何获取 Cookie

- **手机端（推荐，可签到社区板块）**：打开米游社 App → 我的 → 设置 → 复制 Cookie。该 Cookie 包含 `stuid`/`stoken`，社区签到必需。
- **电脑端（可签到游戏）**：登录 mihoyo 相关网页后按 F12 打开开发者工具 → Network 标签 → 刷新页面 → 复制任意请求头中的 Cookie。

## 注意事项

- 签到接口使用米游社官方 API（`bbs-api.miyoushe.com`、`api-takumi.mihoyo.com`），请求会携带必要的 DS 签名。
- 若触发风控验证码（retcode 1034），插件无法自动通过，请稍后在米游社手动签到。
- Cookie 会过期，失效后请在 WebUI 插件配置中重新填写。
- 插件只做每日签到，不包含看帖/点赞/分享等米游币任务，以免触发风控。

## 故障排查

### 提示「Cookie 无效或过期 / 登录失效（-100）」

表示米游社接口判定 Cookie 登录状态失效，常见原因与解决方法：

1. **Cookie 确实过期了（最常见）**：米游社 Cookie 有时效性，请重新登录后复制新 Cookie 更新到插件配置。
   - 社区签到（大别野等）：从**米游社 App** 复制完整 Cookie（须含 `stuid`/`stoken`）。
   - 游戏签到：登录 mihoyo 相关网页后 F12 → Network 复制请求头 Cookie。
2. **复制时带入了换行/引号/多余空格**：插件 v1.0.1 起会自动清理，若仍失败请检查粘贴内容是否完整。
3. **只复制了部分字段**：先发送 `/mys测试`，查看「字段检测」结果——`stuid`/`stoken`/`mid`/`ltoken` 应有 ✅。若 `stoken` 为 ❌，说明你的 Cookie 不是 App 版，社区签到无法使用（游戏签到仍可）。
4. **新旧 Cookie 混用**：确保 `stuid`、`stoken`、`mid` 来自**同一个账号**的**同一次登录**。

发送 `/mys测试` 可以看到 Cookie 有效性和字段诊断信息。
